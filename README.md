## What This Is

23 interactive board games — each with 24 real-world workplace scenarios — built for vocational students in Phnom Penh, Cambodia. Every board:

- Works on any Android phone, including cheap older devices
- Works **offline** once loaded — no internet required during play
- Integrates **Khmer script** on every square
- Draws scenarios from **real Phnom Penh workplaces** — Friends the Restaurant, Romdeng, local barbershops, motorcycle workshops
- Embeds directly into **Moodle** and any LMS via iframe or SCORM
- Requires **no login, no account, no installation**

## How to Use This Resource

### For Students
Just open a link above on your phone. No login needed.  
**Add to your home screen** when prompted — the board then works offline.

### For Trainers — Embedding in Moodle
Add a **Page** activity in your Moodle course. In the HTML editor, paste:

```html
<iframe 
  src="https://johntan-tvet.github.io/vocational-boards/boards/fnb/board1-orientation.html" 
  width="100%" 
  height="700px" 
  frameborder="0"
  allowfullscreen>
</iframe>
```

Replace the URL with the board you want. The board appears inside Moodle. Students never leave the course environment.

## Instructional Architecture

Every board is built on the **E3R3 Professional Learning Framework**:

| Element | How it appears in the boards |
|---------|------------------------------|
| **Examine** | Each square presents a real workplace situation |
| **Explore** | Three options — learners consider alternatives |
| **Evaluate** | Immediate consequence feedback after every choice |
| **Reflect** | Snake outcomes explain why the wrong choice matters |
| **Reform** | Snakes return learners to earlier squares — revisiting with new understanding |
| **Reinforce** | Ladders reward mastery of complex situations |

Published framework: [DOI: 10.5281/zenodo.19376122](https://doi.org/10.5281/zenodo.19376122)
